# Pulso

Pulso detecta sola cuándo se va y cuándo vuelve la luz en tu casa, lleva la cuenta de las horas sin luz y le avisa a tu familia, sin que tengas que reportar nada.

Proyecto personal de Isaac Mendoza, hecho en Maracay. Android primero. Este repo tiene la app; el backend está en `pulso-api`.
